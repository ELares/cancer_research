## The claim-to-metric gap

242 combination papers assert an interaction in words -- *synergistic*, *synergy*, *potentiates* -- and 8 of them (3.31%) name a metric anywhere a reader can see it. The remaining 234 state the conclusion without the scale it was measured on.

This share measures named metrics alongside claim words in titles and abstracts. It does not measure whether a metric was computed elsewhere in the paper. Without measured reporting rates for both vocabularies, these counts establish neither the true computation rate nor a bound or bias direction for the full-paper gap.

## What this means for the protocol

The protocol names both Bliss and Chou-Talalay combination index. Bliss is named in 1 control records and Chou-Talalay combination index in 46. These observed mention counts describe the available abstract text, not which metric is preferable or how often each was computed.

Report the raw dose-response matrix alongside whichever index is computed. An index is a number on a scale, and the scales are not interconvertible without the underlying data -- a Chou-Talalay CI and a Bliss excess answer different questions about the same experiment. A collaborator who publishes the matrix lets a reader holding the other metric recompute; one who publishes only the index does not.

## What this does not measure

Whether a metric was computed. Title and abstract searches may miss metrics named elsewhere or match a name without its calculation. Metric-specific reporting rates are unknown, so observed mention ordering need not match the ordering of computation rates. This analysis also says nothing about whether a reported synergy is real: naming a scale is not the same as using it well.
