# Which synergy metric the ferroptosis literature names

Generated by `scripts/census_synergy_metrics.py` over the 13,346 census articles carrying the `Ferroptosis` descriptor, of which 916 (6.86%) describe a combination. `analysis/p1-wetlab-protocol.md` states its falsification threshold in one metric's terms, and a threshold is only as useful as the comparison it enables.

**The subject arm cannot rank these metrics and the control can.** Only 14 of the 13,346 ferroptosis articles name any metric at all -- below the 30 this analysis requires before reading an order off it -- so the ranking below comes from the same rules applied to 108,712 census records sampled 1-in-40 shards, where *Chou-Talalay combination index* leads with 46 against 15 for the next. The thin subject arm AGREES with it, which is the most it can support.

The protocol names that metric, so its stated threshold is on the scale the literature names most often.

## The claim-to-metric gap

242 combination papers assert an interaction in words -- *synergistic*, *synergy*, *potentiates* -- and 8 of them (3.31%) name a metric anywhere a reader can see it. The remaining 234 state the conclusion without the scale it was measured on.

**This ratio is an upper bound on how bad the real gap is, and it is biased in the direction that flatters the field.** A metric is usually computed in a figure and quoted in Results; a claim word is abstract-native. So the true share of papers that COMPUTED something is higher than this, and the share a reader can FIND without opening the paper is what is measured here.

## What this means for the protocol

**Computing both indices is the right call and now has a measured reason.** The simulation's own output is a Bliss excess, and Bliss appears in 1 of the 108,712 control records against 46 for Chou-Talalay combination index. So the model speaks one scale and the literature a reader would compare against speaks another. A protocol reporting only the model's metric would produce a number with nothing published beside it; one reporting only the field's would not connect to the model it was built to test. The protocol already computes both.

Report the raw dose-response matrix alongside whichever index is computed. An index is a number on a scale, and the scales are not interconvertible without the underlying data -- a Chou-Talalay CI and a Bliss excess answer different questions about the same experiment. A collaborator who publishes the matrix lets a reader holding the other metric recompute; one who publishes only the index does not.

## What this does not measure

Whether a metric was computed. Counting title and abstract UNDERCOUNTS every metric heavily and the absolute shares here are far below the real ones. The undercount applies to every metric alike, which is why the comparison BETWEEN metrics -- the question the protocol needs answered -- survives it while the absolute rates do not. It also says nothing about whether a reported synergy is real: naming a scale is not the same as using it well.
