# The literatures this project's descriptor map cannot name

Generated by `scripts/census_unnamed_modalities.py` over 4,403,994 census records. 9 modalities are reported throughout this project as *not measurable* rather than as zero, because this project's descriptor map names no usable MeSH leaf for them. That is the right call and an incomplete one: a reader meeting the phrase 9 times is entitled to ask how big the thing is. It is also not the same claim as "MeSH has no descriptor", which is what this page used to say and what `analysis/descriptor-absence-audit.md` corrects.

Measured against the census's whole descriptor vocabulary in `analysis/descriptor-absence-audit.md`: no descriptor names or contains `bioelectric`, `frequency-therapy`, `ttfields`; a descriptor CONTAINS `cold-atmospheric-plasma`, `cuproptosis`, `radioligand-therapy` while meaning far more, so a count of it over-counts; the census carries a NAME-EXACT descriptor for `disulfidptosis`, `electrolysis`, `targeted-protein-degradation`, so these are volume-measurable at census scale and unusable only as a recall reference. Those 3 verdicts license different claims and collapsing them into "MeSH has no descriptor" is what that page corrects.

They are measurable on one instrument. This project's keyword vocabulary reads title and abstract, so it counts a modality whose name authors write even where NLM has no term for it. Together these nine carry **11,830 articles and 490 clinical trials** -- which is what *not measurable by descriptor* actually amounts to.

## Why these rows are weaker than the ones beside them

Every other modality in this project can be measured twice, and the agreement between a descriptor arm and a keyword arm is a validity test -- it caught a 15-fold artifact in sonodynamic therapy's trial share, where a descriptor was counting ultrasound hyperthermia. **For most of these rows that test is unavailable BY CONSTRUCTION**: there is no second arm, and the absence of one is exactly what puts a modality on this list.

**BY CONSTRUCTION was too strong for `disulfidptosis`, `electrolysis`, `targeted-protein-degradation`**, and that is #952's correction to this page rather than an addition to it: the census carries a name-exact descriptor for each of them, so a second arm exists and the agreement is measured in `analysis/descriptor-absence-audit.md`. The justification above holds for the remaining rows.

So these numbers rest on a single instrument whose measured mechanism precision is 82.5%, with no independent check available. They should be read as LESS certain than the descriptor-backed figures elsewhere in this project, not more -- which is the opposite of how a precise-looking count in a table tends to read.

## The failure mode is visible, not hypothetical

1 modalities have 1990-and-earlier literature above a tenth of their total, marked * above: `electrolysis`. None of these modalities existed then, so those records are the vocabulary matching an older use of its own words.

Two mechanisms, both already traced elsewhere in this project. A term can be a common word or a short abbreviation that collides -- `echt` matches inside "liechtenstein". And a term can predate the modality it now names: `copper ionophore` was applied to disulfiram in 1982, four decades before cuproptosis was named, so `cuproptosis` counts 1980s chemistry as its own literature.

The affected counts are upper bounds. They are published rather than filtered because a date cut-off would be a second judgement layered on the first, and the per-row pre-1990 share lets a reader apply their own.

## What this changes about the phrase

*Not measurable* should mean **not measurable by descriptor**, which is a statement about MeSH rather than about the field. Used without that qualifier it invites exactly the reading it was meant to prevent -- that there is nothing there. There is: radioligand therapy alone carries hundreds of indexed trials while having no MeSH descriptor of its own.
